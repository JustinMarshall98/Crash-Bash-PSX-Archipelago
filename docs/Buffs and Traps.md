
# Crash Bash - Extra Item documentation

## What do the Progressive Minigame Buff items do?

### Ballistix
You'll start with 2 additional lives for each Progressive Ballistix Buff.
### Crate Crush
Your opponents will start with a bit less health for each Progressive Crate Crush Buff.
### Polar Push
You'll start with 10 seconds more on the clock for each Progressive Polar Push Buff.
### Pogo Pandemonium
You'll start with 10 additional points for each Progressive Pogo Pandemonium Buff.
### Tank Wars
Your opponents will start with a bit less health for each Progressive Tank Wars Buff.
### Crash Dash
You'll have 1 less lap to do for each Progressive Crash Dash Buff.
### Medieval Mayhem
You'll start with 10 additional points for each Progressive Medieval Mayhem Buff.
### Bosses
For each Progressive Boss Buff:
Papu Pummel / Bearminator - No change.
Big Bad Fox - Komodo Joe and Komodo Moe will start with less HP.
Oxide Ride - You will have increased starting HP.

## What traps are there?
Currently the only trap available is the Character Swap Trap (of which a maximum of 2 will be added to the game with the option on).
A character swap will randomize all the characters in your adventure mode save. This only takes hold after crossing a loading screen.

## My world didn't generate any traps or buff items!! What gives?
You must either increase the number of Trophy Rounds or include Platinum Relic Challenges to increase the number of locations
your game has, otherwise there isn't enough space for non-progression items to be created.
